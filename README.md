## How to Use

1. **Open the website**: Simply open `index.html` in a web browser
2. **Navigate**: Use the navigation menu to explore different sections
3. **Search**: Use the search bar on the blog page to find specific articles
4. **Filter**: Click on categories to filter articles
5. **Read**: Click "Read More" on any article to view full content
6. **Contact**: Use the contact form to send messages

## Deployment

### Before Deploying
1. Update all URLs in meta tags from `https://theweavingtale.com` to your actual domain
2. Update sitemap.xml with your domain
3. Update robots.txt with your domain
4. Add Google Analytics tracking code (optional)
5. Add Google Search Console verification (optional)

### After Deploying
1. Submit sitemap to Google Search Console
2. Submit sitemap to Bing Webmaster Tools
3. Test all pages with Google's Mobile-Friendly Test
4. Check page speed with Google PageSpeed Insights
5. Verify structured data with Google's Rich Results Test

## Customization

### To add new articles:
Edit `js/data.js` and add new objects to the `articles` array.

### To add new products:
Edit `js/data.js` and add new objects to the `products` array.

### To change colors:
Edit CSS variables in `css/style.css`:
```css
:root {
    --primary-color: #2c3e50;
    --secondary-color: #e74c3c;
    --accent-color: #3498db;
}
```

### To change images:
Replace image URLs in the HTML files or data.js file.
